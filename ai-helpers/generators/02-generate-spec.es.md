# Generador: Elemento de Breakdown → Spec

## Entrada
Lee el PR indicado por el usuario desde el desglose en 
`ai-helpers/idea-development/02-breakdown.es.md`.

## Proceso
Desarrolla una especificación técnica precisa siguiendo el flujo 
`.agents/workflows/deep-plan.es.md` en modo **strict**. La especificación debe:

1. Listar cada archivo a crear/modificar con rutas exactas.
2. Definir comandos de validación para cada etapa.
3. Limitar las etapas a un máximo de 3-5 archivos.

## Salida
Escribe la especificación en `ai-helpers/idea-development/03-spec.es.md`.
